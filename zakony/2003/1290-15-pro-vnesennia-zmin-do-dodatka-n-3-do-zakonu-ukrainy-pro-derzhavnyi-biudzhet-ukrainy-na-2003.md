# Про внесення змін до додатка N 3 до Закону України "Про Державний бюджет України на 2003 рік"

ЗАКОН УКРАЇНИ

Про внесення змін до додатка N 3 до Закону України "Про Державний бюджет України на 2003 рік"

( Відомості Верховної Ради України (ВВР), 2004, N 14, ст.191 )

Верховна Рада України постановляє:

1\. Внести зміни до додатка N 3 до Закону України "Про Державний бюджет України на 2003 рік" ( 380-15 ) (Відомості Верховної Ради України, 2003 р., N 10-11, ст. 86, N 33-34, ст. 267; 2004 р., N 5, ст.32, 33) відповідно до додатка до цього Закону.

2\. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 18 листопада 2003 року N 1290-IV

Додаток до Закону України "Про внесення змін до додатка N 3 до Закону України "Про Державний бюджет України на 2003 рік"
