# Про прийняття зміни до Конвенції про права дитини

ЗАКОН УКРАЇНИ

Про прийняття зміни до Конвенції про права дитини

( Відомості Верховної Ради України (ВВР), 2003, N 29, ст.227 )

Верховна Рада України постановляє:

Прийняти зміну до пункту 2 статті 43 Конвенції про права дитини ( 995\_021 ), схвалену Резолюцією Генеральної Асамблеї ООН ( 995\_b10 ) від 21 грудня 1995 року N 50/155 (додається\*).

Президент України Л.КУЧМА

м. Київ, 3 квітня 2003 року N 717-IV

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ \* Додається до оригіналу.
