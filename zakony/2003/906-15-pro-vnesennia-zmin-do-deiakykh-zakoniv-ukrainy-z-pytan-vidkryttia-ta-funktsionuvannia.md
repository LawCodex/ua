# Про внесення змін до деяких законів України з питань відкриття та функціонування банківських рахунків

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України з питань відкриття та функціонування банківських рахунків

( Відомості Верховної Ради України (ВВР), 2003, N 38, ст.319 )

{ Із змінами, внесеними згідно з Кодексом N 2755-VI ( 2755-17 ) від 02.12.2010, ВВР, 2011, N 13-14, N 15-16, N 17, ст.112 Законами N 5083-VI ( 5083-17 ) від 05.07.2012, ВВР, 2013, N 33, ст.435 N 1591-IX ( 1591-20 ) від 30.06.2021 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

{ Пункт 1 розділу I втратив чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010 }

{ Пункт 2 розділу I втратив чинність на підставі Закону N 5083-VI ( 5083-17 ) від 05.07.2012 }

{ Пункт 3 розділу I втратив чинність на підставі Закону N 1591-IX ( 1591-20 ) від 30.06.2021 }

II. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 5 червня 2003 року N 906-IV
