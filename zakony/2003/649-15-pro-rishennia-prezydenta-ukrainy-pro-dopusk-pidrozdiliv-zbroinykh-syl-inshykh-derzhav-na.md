# Про рішення Президента України про допуск підрозділів збройних сил інших держав на територію України у 2003 році для участі в багатонаціональних військових навчаннях

ЗАКОН УКРАЇНИ

Про рішення Президента України про допуск підрозділів збройних сил інших держав на територію України у 2003 році для участі в багатонаціональних військових навчаннях

( Відомості Верховної Ради України (ВВР), 2003, N 26, ст.186 )

Верховна Рада України постановляє:

Рішення Президента України про допуск підрозділів збройних сил інших держав на територію України у 2003 році для участі в багатонаціональних військових навчаннях ( 223/2003 ) схвалити.

Президент України Л.КУЧМА

м. Київ, 3 квітня 2003 року N 649-IV
