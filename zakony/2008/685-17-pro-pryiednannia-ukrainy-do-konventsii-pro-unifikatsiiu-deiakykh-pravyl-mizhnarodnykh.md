# Про приєднання України до Конвенції про уніфікацію деяких правил міжнародних повітряних перевезень

ЗАКОН УКРАЇНИ

Про приєднання України до Конвенції про уніфікацію деяких правил міжнародних повітряних перевезень

( Відомості Верховної Ради України (ВВР), 2009, N 15, ст.201 )

Верховна Рада України постановляє:

Приєднатися до Конвенції про уніфікацію деяких правил міжнародних повітряних перевезень ( 995\_594 ), вчиненої 28 травня 1999 року у м. Монреалі (додається).

Президент України В.ЮЩЕНКО

м. Київ, 17 грудня 2008 року N 685-VI
