# Про ратифікацію Гарантійної угоди від 28 листопада 2007 року між Україною (Гарант) та Європейським банком реконструкції та розвитку (Банк)

ЗАКОН УКРАЇНИ

Про ратифікацію Гарантійної угоди від 28 листопада 2007 року між Україною (Гарант) та Європейським банком реконструкції та розвитку (Банк)

( Відомості Верховної Ради України (ВВР), 2009, N 9, ст.118 )

Верховна Рада України постановляє:

Гарантійну угоду від 28 листопада 2007 року між Україною (Гарант) та Європейським банком реконструкції та розвитку (Банк) ( 985\_013 ) ратифікувати (додається).

Президент України В.ЮЩЕНКО

м. Київ, 24 вересня 2008 року N 590-VI
