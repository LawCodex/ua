# Про ратифікацію Конвенції Міжнародної організації праці 1979 року N 153 про тривалість робочого часу та періоди відпочинку на дорожньому транспорті

ЗАКОН УКРАЇНИ

Про ратифікацію Конвенції Міжнародної організації праці 1979 року N 153 про тривалість робочого часу та періоди відпочинку на дорожньому транспорті

( Відомості Верховної Ради України (ВВР), 2008, N 15, ст.118 )

Верховна Рада України постановляє:

Ратифікувати Конвенцію Міжнародної організації праці 1979 року N 153 про тривалість робочого часу та періоди відпочинку на дорожньому транспорті ( 993\_025 ) (додається).

Президент України В.ЮЩЕНКО

м. Київ, 6 березня 2008 року N 129-VI
