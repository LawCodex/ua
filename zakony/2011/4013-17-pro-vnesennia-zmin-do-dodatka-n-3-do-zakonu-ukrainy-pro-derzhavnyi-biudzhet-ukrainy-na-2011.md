# Про внесення змін до додатка N 3 до Закону України "Про Державний бюджет України на 2011 рік"

ЗАКОН УКРАЇНИ

Про внесення змін до додатка N 3 до Закону України "Про Державний бюджет України на 2011 рік"

( Відомості Верховної Ради України (ВВР), 2012, N 23, ст.245 )

Верховна Рада України постановляє:

1\. Внести зміни до додатка N 3 до Закону України "Про Державний бюджет України на 2011 рік" ( 2857-17 ) (Відомості Верховної Ради України, 2011 р., N 7-8, ст. 52, N 42, ст. 427, ст. 429, N 44, ст. 468, ст. 474, N 45, ст. 483; 2012 р., N 1, ст. 1, N 5, ст. 32, N 21, ст. 192, ст. 202, N 22, ст. 212, ст. 213, ст. 214, ст. 215, N 23, ст. 228, ст. 229, ст. 243, ст. 244) згідно з додатком до цього Закону.

2\. Цей Закон набирає чинності з дня, наступного за днем його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 4 листопада 2011 року N 4013-VI

Додаток до Закону України "Про внесення змін до додатка N 3 до Закону України "Про Державний бюджет України на 2011 рік"
