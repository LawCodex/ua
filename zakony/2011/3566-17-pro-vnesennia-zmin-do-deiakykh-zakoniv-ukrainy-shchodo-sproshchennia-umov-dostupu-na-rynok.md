# Про внесення змін до деяких законів України щодо спрощення умов доступу на ринок телекомунікаційних послуг

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України щодо спрощення умов доступу на ринок телекомунікаційних послуг

( Відомості Верховної Ради України (ВВР), 2012, N 5, ст.35 )

{ Із змінами, внесеними згідно із Законом N 1089-IX ( 1089-20 ) від 16.12.2020 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

{ Пункт 1 розділу I втратив чинність на підставі Закону N 1089-IX ( 1089-20 ) від 16.12.2020 }

{ Пункт 2 розділу I втратив чинність на підставі Закону N 1089-IX ( 1089-20 ) від 16.12.2020 }

II. Прикінцеві положення

1\. Цей Закон набирає чинності з дня, наступного за днем його опублікування.

2\. Кабінету Міністрів України в шестимісячний строк з дня набрання чинності цим Законом:

привести свої нормативно-правові акти у відповідність із цим Законом;

забезпечити приведення центральними органами виконавчої влади їх нормативно-правових актів у відповідність із цим Законом.

Президент України В.ЯНУКОВИЧ
