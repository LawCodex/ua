# Про ратифікацію Угоди про вільну торгівлю між Україною та державами ЄАВТ, Угоди про сільське господарство між Україною та Королівством Норвегія, Угоди про сільське господарство між Україною та Ісландією та Угоди про сільське господарство між Україною та Швейцарською Конфедерацією

ЗАКОН УКРАЇНИ

Про ратифікацію Угоди про вільну торгівлю між Україною та державами ЄАВТ, Угоди про сільське господарство між Україною та Королівством Норвегія, Угоди про сільське господарство між Україною та Ісландією та Угоди про сільське господарство між Україною та Швейцарською Конфедерацією

( Відомості Верховної Ради України (ВВР), 2012, N 27, ст.284 )

Верховна Рада України постановляє:

Угоду про вільну торгівлю між Україною та державами ЄАВТ ( 998\_456 ), Угоду про сільське господарство між Україною та Королівством Норвегія ( 578\_022 ), Угоду про сільське господарство між Україною та Ісландією ( 352\_003 ) та Угоду про сільське господарство між Україною та Швейцарською Конфедерацією ( 756\_036 ), які вчинені 24 червня 2010 року в м. Рейк'явіку, ратифікувати (додаються).

Угода про вільну торгівлю між Україною та державами ЄАВТ ( 998\_456 ) набирає чинності з першого дня третього місяця, що слідує за датою, коли Україна і принаймні одна з держав ЄАВТ здали на зберігання депозитарію документи про ратифікацію, прийняття або схвалення цієї Угоди.

Угода про сільське господарство між Україною та Королівством Норвегія ( 578\_022 ), Угода про сільське господарство між Україною та Ісландією ( 352\_003 ) та Угода про сільське господарство між Україною та Швейцарською Конфедерацією ( 756\_036 ) набирають чинності в той самий день, коли Угода про вільну торгівлю ( 998\_456 ) набирає чинності між Україною та відповідною державою ЄАВТ.

Президент України В.ЯНУКОВИЧ
