# Про внесення змін до Митного тарифу України, затвердженого Законом України "Про Митний тариф України", та інших законів України щодо опису та ставок ввізного мита на деякі товари

ЗАКОН УКРАЇНИ

Про внесення змін до Митного тарифу України, затвердженого Законом України "Про Митний тариф України", та інших законів України щодо опису та ставок ввізного мита на деякі товари

( Відомості Верховної Ради України (ВВР), 2012, N 38, ст.455 )

{ Із змінами, внесеними згідно із Законом N 584-VII ( 584-18 ) від 19.09.2013, ВВР, 2014, N 20-21, ст.740 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:
