# Про внесення змін до деяких законів України щодо удосконалення законодавства про заборону грального бізнесу в Україні

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України щодо удосконалення законодавства про заборону грального бізнесу в Україні

( Відомості Верховної Ради України (ВВР), 2011, N 45, ст.492 )

{ Із змінами, внесеними згідно із Законами N 580-VIII ( 580-19 ) від 02.07.2015, ВВР, 2015, N 40-41, ст.379 N 768-IX ( 768-20 ) від 14.07.2020 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

{ Пункт 1 розділу I втратив чинність на підставі Закону N 580-VIII ( 580-19 ) від 02.07.2015 }

{ Пункт 2 розділу I втратив чинність на підставі Закону N 768-IX ( 768-20 ) від 14.07.2020 }

II. Цей Закон набирає чинності з дня, наступного за днем його опублікування.

Президент України В.ЯНУКОВИЧ

м. Київ, 19 травня 2011 року N 3383-VI
