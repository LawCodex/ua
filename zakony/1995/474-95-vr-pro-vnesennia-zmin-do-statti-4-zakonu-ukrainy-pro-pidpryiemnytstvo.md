# Про внесення змін до статті 4 Закону України "Про підприємництво"

ЗАКОН УКРАЇНИ

Про внесення змін до статті 4 Закону України "Про підприємництво"

( Відомості Верховної Ради України (ВВР), 1995, N 45, ст.335 )

Верховна Рада України постановляє :

1\. Абзац дванадцятий частини другої статті 4 Закону України "Про підприємництво" ( 698-12 ) (Відомості Верховної Ради УРСР, 1991 р., N 14, ст.168; Відомості Верховної Ради України, 1992 р., N 51, ст.680; 1993 р., N 30, ст.322, ст.324, N 51, ст.481, ст.482; 1994 р., N 3, ст.13, N 28, ст.234, N 33, ст.301, N 40, ст.366, N 49, ст.434; 1995 р., N 7, ст.47, N 10, ст.64, N 30, ст.232) викласти в такій редакції:

"торговельна діяльність у сфері оптової, роздрібної торгівлі та громадського харчування щодо реалізації продовольчих і непродовольчих товарів, алкогольних напоїв, тютюнових виробів".

2\. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 14 грудня 1995 року N 474/95-ВР
