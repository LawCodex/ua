# Про внесення зміни до статті 4 Закону України "Про використання земель оборони" щодо будівництва житла для військовослужбовців та членів їхніх сімей

ЗАКОН УКРАЇНИ

Про внесення зміни до статті 4 Закону України "Про використання земель оборони" щодо будівництва житла для військовослужбовців та членів їхніх сімей

( Відомості Верховної Ради України (ВВР), 2011, N 12, ст.79 )

Верховна Рада України постановляє:

1\. Частину другу статті 4 Закону України "Про використання земель оборони" ( 1345-15 ) (Відомості Верховної Ради України, 2004 р., N 14, ст. 209; 2009 р., N 19, ст. 257) викласти в такій редакції:

"Землі оборони можуть використовуватися для будівництва об'єктів соціально-культурного призначення, житла для військовослужбовців та членів їхніх сімей, а також соціального та доступного житла без зміни їх цільового призначення".

2\. Цей Закон набирає чинності з дня його опублікування.
