# Про затвердження указів Президії Верховної Ради Української РСР про внесення змін і доповнень до деяких законодавчих актів Української РСР

ЗАКОН УКРАЇНСЬКОЇ РАДЯНСЬКОЇ СОЦІАЛІСТИЧНОЇ РЕСПУБЛІКИ

Про затвердження указів Президії Верховної Ради Української РСР про внесення змін і доповнень до деяких законодавчих актів Української РСР

( Відомості Верховної Ради (ВВР), 1988, N 47, ст. 1115 )

{ Із змінами, внесеними згідно із Законами N 1634-XII ( 1634-12 ) від 08.10.91, ВВР, 1991, N 50, ст.704 N 2215-IX ( 2215-20 ) від 21.04.2022 }

Верховна Рада Української Радянської Соціалістичної Республіки постановляє:

Затвердити укази Президії Верховної Ради Української РСР:

від 3 серпня 1988 "Про внесення змін до статті 75 Виправно-трудового кодексу Української РСР" ( 6346-11 );

{ Абзац не застосовується на території України згідно із Законом N 2215-IX ( 2215-20 ) від 21.04.2022 }

від 3 серпня 1988 року "Про відповідальність за порушення встановленого порядку організації і проведення зборів, мітингів, вуличних походів і демонстрацій" ( 6347-11 );

( Абзац втратив чинність на підставі Закону ВР N 1634-XII ( 1634-12 ) від 08.10.91 )

від 25 жовтня 1988 року "Про внесення змін і доповнень до деяких законодавчих актів Української РСР" ( 6757-11 );

від 25 жовтня 1988 року "Про вилучення вогнестрільної зброї і бойових припасів у деяких категорій громадян" ( 6758-11 ).

Голова Президії Верховної Ради Української РСР В.ШЕВЧЕНКО

Секретар Президії Верховної Ради Української РСР М.ХОМЕНКО
