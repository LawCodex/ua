# Про ратифікацію протоколів, що стосуються зміни Конвенції про міжнародну цивільну авіацію

ЗАКОН УКРАЇНИ

Про ратифікацію протоколів, що стосуються зміни Конвенції про міжнародну цивільну авіацію

( Відомості Верховної Ради України (ВВР), 2002, N 41, ст.299 )

Верховна Рада України постановляє:

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_423 ) (стаття 3 bis), від 10 травня 1984 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_889 ) (стаття 45), від 14 червня 1954 року,

Протокол, що стосується певних змін Конвенції про міжнародну цивільну авіацію ( 995\_887 ) (пункт "а" статті 48, пункт "е" статті 49 та стаття 61), від 14 червня 1954 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_897 ) (пункт "а" статті 48), від 15 вересня 1962 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_895 ) (пункт "а" статті 50), від 21 червня 1961 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_899 ) (пункт "а" статті 50), від 12 березня 1971 року,

Протокол, що стосується зміни до пункту "а" статті 50 Конвенції про міжнародну цивільну авіацію ( 995\_929 ), від 16 жовтня 1974 року,

Протокол, що стосується зміни до пункту "а" статті 50 Конвенції про міжнародну цивільну авіацію ( 995\_931 ), від 26 жовтня 1990 року,

Протокол, що стосується зміни до статті 56 Конвенції про міжнародну цивільну авіацію ( 995\_898 ), від 7 липня 1971 року,

Протокол, що стосується зміни до статті 56 Конвенції про міжнародну цивільну авіацію ( 995\_930 ), від 6 жовтня 1989 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_886 ) (стаття 93 bis), від 27 травня 1947 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_566 ), від 30 вересня 1977 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_932 ), від 29 вересня 1995 року,

Протокол, що стосується зміни Конвенції про міжнародну цивільну авіацію ( 995\_933 ), від 1 жовтня 1998 року, -

ратифікувати (додаються\*).

Президент України Л.КУЧМА

м. Київ, 11 липня 2002 року N 112-IV

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ \* Додаються до оригіналу.
