# Про прийняття Четвертої поправки до Угоди Міжнародного валютного фонду

ЗАКОН УКРАЇНИ

Про прийняття Четвертої поправки до Угоди Міжнародного валютного фонду

( Відомості Верховної Ради України (ВВР), 2002, N 41, ст.298 )

Верховна Рада України постановляє:

Четверту поправку до Угоди Міжнародного валютного фонду щодо спеціального одноразового надання спеціальних прав запозичення (СПЗ) ( 995\_921 ), схвалену Резолюцією Ради Керуючих Міжнародного валютного фонду N 52-4 від 23 вересня 1997 року ( 996\_730 ), прийняти (додається\*).

Президент України Л.КУЧМА

м. Київ, 11 липня 2002 року N 111-IV

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ \* Додається до оригіналу.
