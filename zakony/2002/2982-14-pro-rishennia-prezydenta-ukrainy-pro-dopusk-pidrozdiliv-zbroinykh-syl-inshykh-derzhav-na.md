# Про рішення Президента України про допуск підрозділів збройних сил інших держав на територію України у 2002 році для участі в багатонаціональних військових навчаннях

ЗАКОН УКРАЇНИ

Про рішення Президента України про допуск підрозділів збройних сил інших держав на територію України у 2002 році для участі в багатонаціональних військових навчаннях

( Відомості Верховної Ради України (ВВР), 2002, N 21-22, ст.136 )

Верховна Рада України постановляє:

Рішення Президента України про допуск підрозділів збройних сил інших держав на територію України у 2002 році для участі в багатонаціональних військових навчаннях ( 25/2002 ) схвалити.

Президент України Л.КУЧМА

м. Київ, 17 січня 2002 року N 2982-III
