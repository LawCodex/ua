# Про ратифікацію Протоколу N 13 до Конвенції про захист прав людини і основоположних свобод, який стосується скасування смертної кари за будь-яких обставин

ЗАКОН УКРАЇНИ

Про ратифікацію Протоколу N 13 до Конвенції про захист прав людини і основоположних свобод, який стосується скасування смертної кари за будь-яких обставин

( Відомості Верховної Ради України (ВВР), 2003, N 4, ст.36 )

{ В редакції Закону N 3436-IV ( 3436-15 ) від 09.02.2006, ВВР, 2006, N 26, ст.216 }

Верховна Рада України постановляє:

Ратифікувати Протокол N 13 до Конвенції про захист прав людини і основоположних свобод, який стосується скасування смертної кари за будь-яких обставин, підписаний від імені України 3 травня 2002 року у м. Вільнюсі (додається\*) ( 994\_180 ).

Президент України Л.КУЧМА

м. Київ, 28 листопада 2002 року N 318-IV
