# Про внесення змін і доповнень до Кримінального і Кримінально-процесуального кодексів України

ЗАКОН УКРАЇНИ

Про внесення змін і доповнень до Кримінального і Кримінально-процесуального кодексів України

( Відомості Верховної Ради України (ВВР), 1997, N 4, ст. 21 )

{ Із змінами, внесеними згідно з Кодексами N 2341-III ( 2341-14 ) від 05.04.2001, ВВР, 2001, N 25-26, ст.131 N 4651-VI ( 4651-17 ) від 13.04.2012, ВВР, 2013, N 9-10, N 11-12, N 13, ст.88 }

Верховна Рада України постановляє:

( Розділ I втратив чинність на підставі Кодексу N 2341-III ( 2341-14 ) від 05.04.2001 - набуває чинності 01.09.2001 )

{ Розділ II втратив чинність на підставі Кодексу N 4651-VI ( 4651-17 ) від 13.04.2012 }
