# Про приєднання України до Часткової Угоди про Європейську Комісію "За демократію через право"

ЗАКОН УКРАЇНИ

Про приєднання України до Часткової Угоди про Європейську Комісію "За демократію через право"

( Відомості Верховної Ради України (ВВР), 1997, N 5, ст. 31 )

Верховна Рада України постановляє:

Приєднатися від імені України до Часткової Угоди про Європейську Комісію "За демократію через право" (Венеціанську Комісію) ( 994\_244 ), 1990 рік.

Голова Верховної Ради України О.МОРОЗ

м. Київ, 22 листопада 1996 року N 547/96-ВР
