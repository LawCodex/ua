# Про внесення змін і доповнень до деяких законодавчих актів України у зв'язку із змінами в Законі Української РСР "Про судоустрій Української РСР"

ЗАКОН УКРАЇНИ

Про внесення змін і доповнень до деяких законодавчих актів України у зв'язку із змінами в Законі Української РСР "Про судоустрій Української РСР"

( Відомості Верховної Ради України (ВВР), 1994, N 26, ст.206 )

{ Із змінами, внесеними згідно з Кодексами N 1618-IV ( 1618-15 ) від 18.03.2004, ВВР, 2004, N 40-41, 42, ст.492 N 4651-VI ( 4651-17 ) від 13.04.2012, ВВР, 2013, N 9-10, N 11-12, N 13, ст.88 }

У зв'язку із змінами в Законі Української РСР "Про судоустрій Української РСР" ( 2022-10 ) Верховна Рада України постановляє:

Внести зміни і доповнення до таких законодавчих актів України:

{ Розділ I втратив чинність на підставі Кодексу N 4651-VI ( 4651-17 ) від 13.04.2012 }

( Розділ II втратив чинність на підставі Кодексу N 1618-IV ( 1618-15 ) від 18.03.2004 )

Президент України Л.КРАВЧУК

м. Київ, 24 лютого 1994 року N 4018-XII
