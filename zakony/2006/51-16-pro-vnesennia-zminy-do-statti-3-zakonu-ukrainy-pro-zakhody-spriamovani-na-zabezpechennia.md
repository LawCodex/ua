# Про внесення зміни до статті 3 Закону України "Про заходи, спрямовані на забезпечення сталого функціонування підприємств паливно-енергетичного комплексу"

ЗАКОН УКРАЇНИ

Про внесення зміни до статті 3 Закону України "Про заходи, спрямовані на забезпечення сталого функціонування підприємств паливно-енергетичного комплексу"

( Відомості Верховної Ради України (ВВР), 2006, N 39, ст.339 )

Верховна Рада України постановляє:

1\. Пункт 3.4 статті 3 Закону України "Про заходи, спрямовані на забезпечення сталого функціонування підприємств паливно-енергетичного комплексу" ( 2711-15 ) (Відомості Верховної Ради України, 2005 p., N 33, ст. 430) викласти в такій редакції:

"3.4. Процедура погашення заборгованості підприємствами паливно-енергетичного комплексу діє до 31 грудня 2006 року".

2\. Цей Закон набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 28 липня 2006 року N 51-V
