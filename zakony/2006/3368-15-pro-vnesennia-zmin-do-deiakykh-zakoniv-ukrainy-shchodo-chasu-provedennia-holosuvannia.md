# Про внесення змін до деяких законів України щодо часу проведення голосування

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України щодо часу проведення голосування

( Відомості Верховної Ради України (ВВР), 2006, N 10-11, ст.97 )

I. Внести зміни до таких законів України:

{ Пункт 1 розділу I втратив чинність на підставі Закону N 2487-VI ( 2487-17 ) від 10.07.2010 }

{ Пункт 2 розділу I втратив чинність на підставі Закону N 4061-VI ( 4061-17 ) від 17.11.2011 }

II. Цей Закон набирає чинності з дня його опублікування.
