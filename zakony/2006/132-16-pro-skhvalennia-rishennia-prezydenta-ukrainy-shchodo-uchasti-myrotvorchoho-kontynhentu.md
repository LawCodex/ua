# Про схвалення рішення Президента України щодо участі миротворчого контингенту України в забезпеченні безпеки Спеціального суду по Республіці Сьєрра-Леоне

ЗАКОН УКРАЇНИ

Про схвалення рішення Президента України щодо участі миротворчого контингенту України в забезпеченні безпеки Спеціального суду по Республіці Сьєрра-Леоне

( Відомості Верховної Ради України (ВВР), 2006, N 43, ст.413 )

Верховна Рада України постановляє:

1\. Схвалити рішення Президента України щодо участі миротворчого контингенту України, який діє у складі Місії ООН у Ліберії ( 1279/2003 ), в забезпеченні безпеки Спеціального суду по Республіці Сьєрра-Леоне ( 674/2006 ).

2\. Фінансування витрат, пов'язаних з участю України в зазначеній миротворчій операції, здійснювати за рахунок коштів Державного бюджету України з подальшим відшкодуванням цих витрат Організацією Об'єднаних Націй.

Президент України В.ЮЩЕНКО

м. Київ, 14 вересня 2006 року N 132-V
