# Про ратифікацію Конвенції про маркування пластичних вибухових речовин з метою їх виявлення

ЗАКОН УКРАЇНИ

Про ратифікацію Конвенції про маркування пластичних вибухових речовин з метою їх виявлення

( Відомості Верховної Ради України (ВВР), 1998, N 14, ст.54 )

Верховна Рада України постановляє:

Конвенцію про маркування пластичних вибухових речовин з метою їх виявлення ( 995\_016 ), підписану від імені України 1 березня 1991 року, ратифікувати.

Голова Верховної Ради України О.МОРОЗ

м. Київ, 3 грудня 1997 року N 687/97-ВР
