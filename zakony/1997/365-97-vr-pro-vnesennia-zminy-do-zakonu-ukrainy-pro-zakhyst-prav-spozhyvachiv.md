# Про внесення зміни до Закону України "Про захист прав споживачів"

ЗАКОН УКРАЇНИ

Про внесення зміни до Закону України "Про захист прав споживачів"

( Відомості Верховної Ради України (ВВР), 1997, N 35, ст.219 )
