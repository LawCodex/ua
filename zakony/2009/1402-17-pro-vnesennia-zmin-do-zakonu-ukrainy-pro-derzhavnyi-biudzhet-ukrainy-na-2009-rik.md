# Про внесення змін до Закону України "Про Державний бюджет України на 2009 рік"

ЗАКОН УКРАЇНИ

Про внесення змін до Закону України "Про Державний бюджет України на 2009 рік"

( Відомості Верховної Ради України (ВВР), 2009, N 41, ст.598 )

Верховна Рада України постановляє:

I. Внести до Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) (із змінами, внесеними законами України від 3 лютого 2009 року N 908-VI ( 908-17 ), від 5 березня 2009 року N 1080-VI ( 1080-17 ) та від 17 березня 2009 року N 1131-VI) ( 1131-17 ) такі зміни:

1\. У статті 1:

у частині першій цифри "238.931.337,1" та "55.233.138,3" замінити відповідно цифрами "238.932.555,4" та "55.234.356,6";

у частині другій цифри "267.393.665,2" та "74.035.616,3" замінити відповідно цифрами "267.394.883,5" та "74.036.834,6".

2\. Внести зміни до додатків N 1, N 3 та N 7 до Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) відповідно до додатків N 1, N 2 та N 3 до цього Закону.

II. Цей Закон набирає чинності з дня його опублікування.

Президент України В.ЮЩЕНКО

м. Київ, 21 травня 2009 року N 1402-VI

Додаток N 1 до Закону України "Про внесення змін до Закону України "Про Державний бюджет України на 2009 рік"

Зміни до додатка N 1 до Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) "Доходи Державного бюджету України на 2009 рік"
