# Про внесення змін до деяких законів України з питань акцизного збору

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України з питань акцизного збору

( Відомості Верховної Ради України (ВВР), 2009, N 32-33, ст.489 )

{ Із змінами, внесеними згідно з Кодексом N 2755-VI ( 2755-17 ) від 02.12.2010, ВВР, 2011, N 13-14, N 15-16, N 17, ст.112 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

{ Пункт 1 розділу I втратив чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010 }

{ Пункт 2 розділу I втратив чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010 }

II. Цей Закон набирає чинності з дня його опублікування, крім підпунктів 1 і 2 пункту 1 розділу I, які набирають чинності з 1 липня 2009 року, та пункту 2 розділу I, який набирає чинності з 1 листопада 2009 року.

Президент України В.ЮЩЕНКО

м. Київ, 31 березня 2009 року N 1202-VI
