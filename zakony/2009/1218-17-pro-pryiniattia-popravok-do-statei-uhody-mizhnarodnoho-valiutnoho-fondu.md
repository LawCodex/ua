# Про прийняття Поправок до Статей Угоди Міжнародного валютного фонду

ЗАКОН УКРАЇНИ

Про прийняття Поправок до Статей Угоди Міжнародного валютного фонду

( Відомості Верховної Ради України (ВВР), 2009, N 32-33, ст.494 )

Верховна Рада України постановляє:

Поправку до Статей Угоди Міжнародного валютного фонду щодо посилення голосу та участі в Міжнародному валютному фонді, схвалену Резолюцією Ради керуючих Міжнародного валютного фонду N 63-2 ( 890\_003 ) від 28 квітня 2008 року, та Поправку до Статей Угоди Міжнародного валютного фонду стосовно розширення інвестиційних повноважень Міжнародного валютного фонду, схвалену Резолюцією Ради керуючих Міжнародного валютного фонду N 63-3 ( 890\_002 ) від 5 травня 2008 року, прийняти (додаються).

Президент України В.ЮЩЕНКО

м. Київ, 1 квітня 2009 року N 1218-VI
