# Про внесення змін до деяких законодавчих актів України з питань акцизного збору

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законодавчих актів України з питань акцизного збору

( Відомості Верховної Ради України (ВВР), 2009, N 32-33, ст.488 )

{ Із змінами, внесеними згідно з Кодексом N 2755-VI ( 2755-17 ) від 02.12.2010, ВВР, 2011, N 13-14, N 15-16, N 17, ст.112 }

Верховна Рада України постановляє:

I. Внести зміни до таких законодавчих актів України:

{ Пункт 1 розділу I втратив чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010 }

{ Пункт 2 розділу I втратив чинність на підставі Кодексу N 2755-VI ( 2755-17 ) від 02.12.2010 }

II. Прикінцеві положення

1\. Цей Закон набирає чинності з 1 травня 2009 року.

2\. Кабінету Міністрів України при підготовці змін до Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ) передбачити спрямування пов'язаних із введенням в дію цього Закону надходжень понад обсяги, визначені у додатку N 1 до Закону України "Про Державний бюджет України на 2009 рік" ( 835-17 ), на:

першочергові заходи та програми з охорони здоров'я (лікування онкологічних, серцево-судинних та судинно-мозкових захворювань, забезпечення медичних заходів по боротьбі з туберкульозом, профілактики та лікування СНІДу);

здійснення фінансової підтримки підприємств агропромислового комплексу;

розвиток мережі автомобільних доріг та мостів.

Президент України В.ЮЩЕНКО

м. Київ, 31 березня 2009 року N 1201-VI
