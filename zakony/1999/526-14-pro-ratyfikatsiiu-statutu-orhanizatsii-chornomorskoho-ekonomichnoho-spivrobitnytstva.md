# Про ратифікацію Статуту Організації Чорноморського Економічного Співробітництва

ЗАКОН УКРАЇНИ

Про ратифікацію Статуту Організації Чорноморського Економічного Співробітництва

( Відомості Верховної Ради України (ВВР), 1999, N 18, ст.145 )

Верховна Рада України постановляє:

Статут Організації Чорноморського Економічного Співробітництва ( 998\_009 ), підписаний 5 червня 1998 року в місті Ялті, ратифікувати.
