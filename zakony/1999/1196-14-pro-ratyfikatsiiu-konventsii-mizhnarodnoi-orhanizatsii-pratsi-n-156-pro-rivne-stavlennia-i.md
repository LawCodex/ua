# Про ратифікацію Конвенції Міжнародної організації праці N 156 про рівне ставлення і рівні можливості для трудящих чоловіків і жінок: трудящі із сімейними обов'язками

ЗАКОН УКРАЇНИ

Про ратифікацію Конвенції Міжнародної організації праці

N 156 про рівне ставлення і рівні можливості для трудящих чоловіків і жінок: трудящі із сімейними обов'язками

( Відомості Верховної Ради України (ВВР), 1999, N 51, ст.452 )

Верховна Рада України постановляє:

Конвенцію Міжнародної організації праці N 156 про рівне ставлення і рівні можливості для трудящих чоловіків і жінок: трудящі із сімейними обов'язками, прийняту 67 сесією Генеральної конференції Міжнародної організації праці 23 червня 1981 року ( 993\_010 ), ратифікувати.

Голова Верховної Ради України О.ТКАЧЕНКО
