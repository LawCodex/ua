# Про внесення зміни до статті 67 Кодексу законів про працю України

ЗАКОН УКРАЇНИ

Про внесення зміни до статті 67 Кодексу законів про працю України

( Відомості Верховної Ради України (ВВР), 1999, N 19, ст.175 )

Верховна Рада України постановляє:

1\. Доповнити статтю 67 Кодексу законів про працю України ( 322-08 ) (Відомості Верховної Ради УРСР, 1971 р., додаток до N 50, ст.375; 1983 р., N 6, ст.87; Відомості Верховної Ради України, 1995 р., N 28, ст.201; 1998 р., N 18, ст.93) частиною третьою такого змісту:

"У випадку, коли святковий або неробочий день (стаття 73) збігається з вихідним днем, вихідний день переноситься на наступний після святкового або неробочого".

2\. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 8 квітня 1999 року N 576-XIV
