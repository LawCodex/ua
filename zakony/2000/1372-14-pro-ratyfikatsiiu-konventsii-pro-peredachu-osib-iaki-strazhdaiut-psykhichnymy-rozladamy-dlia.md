# Про ратифікацію Конвенції про передачу осіб, які страждають психічними розладами, для проведення примусового лікування

ЗАКОН УКРАЇНИ

Про ратифікацію Конвенції про передачу осіб, які страждають психічними розладами, для проведення примусового лікування

( Відомості Верховної Ради України (ВВР), 2000, N 6-7, ст.43 )

Верховна Рада України постановляє:

Конвенцію про передачу осіб, які страждають психічними розладами, для проведення примусового лікування, підписану від імені України 28 березня 1997 року в м. Москві ( 997\_028 ), ратифікувати з таким застереженням:

Україна виконуватиме положення частини третьої статті 10 Конвенції щодо проведення нового розслідування чи судового розгляду справи в разі скасування рішення суду щодо проведення примусового лікування за умови, що копія цього рішення, матеріали кримінальної справи та інші необхідні документи будуть надіслані після виконання всіх слідчих та інших процесуальних дій, можливих за відсутності особи, яка страждає психічними розладами.

Голова Верховної Ради України О.ТКАЧЕНКО

м. Київ, 11 січня 2000 року N 1372-XIV
