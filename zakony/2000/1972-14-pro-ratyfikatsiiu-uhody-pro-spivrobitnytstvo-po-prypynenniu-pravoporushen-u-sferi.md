# Про ратифікацію Угоди про співробітництво по припиненню правопорушень у сфері інтелектуальної власності

ЗАКОН УКРАЇНИ

Про ратифікацію Угоди про співробітництво по припиненню правопорушень у сфері інтелектуальної власності

( Відомості Верховної Ради України (ВВР), 2000, N 45, ст.380 )

Верховна Рада України постановляє:

Угоду про співробітництво по припиненню правопорушень у сфері інтелектуальної власності ( 997\_154 ), підписану 6 березня 1998 року у м. Москві, ратифікувати.

Президент України Л.КУЧМА

м. Київ, 21 вересня 2000 року N 1972-III
