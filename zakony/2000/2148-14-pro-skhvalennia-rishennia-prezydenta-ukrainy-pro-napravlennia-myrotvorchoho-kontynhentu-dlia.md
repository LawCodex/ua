# Про схвалення рішення Президента України про направлення миротворчого контингенту для участі України в Місії Організації Об'єднаних Націй в Сьєрра-Леоне

ЗАКОН УКРАЇНИ

Про схвалення рішення Президента України про направлення миротворчого контингенту для участі України в Місії Організації Об'єднаних Націй в Сьєрра-Леоне

( Відомості Верховної Ради України (ВВР), 2001, N 4, ст.20 )

Верховна Рада України постановляє:

Рішення Президента України про направлення миротворчого контингенту для участі України в Місії Організації Об'єднаних Націй в Сьєрра-Леоне ( 1319/2000 ) схвалити.

Президент України Л.КУЧМА

м. Київ, 14 грудня 2000 року N 2148-III
