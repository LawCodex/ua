# Про внесення змін до деяких законів України у зв'язку з прийняттям Закону України "Про правовий режим надзвичайного стану"

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України у зв'язку з прийняттям Закону України "Про правовий режим надзвичайного стану"

( Відомості Верховної Ради України (ВВР), 2002, N 7, ст.52 )

{ Із змінами, внесеними згідно з Кодексом N 436-IV ( 436-15 ) від 16.01.2003, ВВР, 2003, N 18, N 19-20, N 21-22, ст.144 Законом

N 2573-IX ( 2573-20 ) від 06.09.2022 }

Верховна Рада України постановляє:

I. Внести зміни до таких законів України:

( Пункт 1 розділу I втрачає чинність з 01.01.2004 року на підставі Кодексу N 436-IV ( 436-15 ) від 16.01.2003 )

{ Пункт 2 розділу I втратив чинність на підставі Закону N 2573-IX ( 2573-20 ) від 06.09.2022 }

II. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 15 листопада 2001 року N 2788-III
