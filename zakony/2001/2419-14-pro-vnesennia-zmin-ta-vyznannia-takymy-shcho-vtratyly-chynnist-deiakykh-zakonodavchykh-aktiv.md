# Про внесення змін та визнання такими, що втратили чинність, деяких законодавчих актів України у зв'язку з прийняттям Закону України "Про державні нагороди України"

ЗАКОН УКРАЇНИ

Про внесення змін та визнання такими, що втратили чинність, деяких законодавчих актів України у зв'язку з прийняттям Закону України "Про державні нагороди України"

( Відомості Верховної Ради України (ВВР), 2001, N 31, ст. 149 )

( Із змінами, внесеними згідно з Кодексом N 2341-III ( 2341-14 ) від 05.04.2001, ВВР, 2001, N 25-26, ст.131 )

Верховна Рада України постановляє:

I. Внести зміни до таких законодавчих актів України:

( Стаття 1 розділу I втратила чинність на підставі Кодексу N 2341-III ( 2341-14 ) від 05.04.2001 )

2\. У назві та тексті статті 39 Закону України "Про місцеве самоврядування в Україні" ( 280/97-ВР ) (Відомості Верховної Ради України, 1997 р., N 24, ст. 170) слова "відзнаками Президента України та присвоєння почесних звань" і "відзнаками Президента України та про присвоєння почесних звань" виключити.

3\. У пункті 5 статті 25 Закону України "Про місцеві державні адміністрації" ( 586-14 ) (Відомості Верховної Ради України, 1999 р., N 20-21, ст. 190) слова "президентськими відзнаками та почесними званнями" виключити.

II. Визнати такими, що втратили чинність:

1\. Указ Президії Верховної Ради Української РСР від 7 травня 1981 року "Про затвердження Положення про державні нагороди Української РСР" ( 1870-10 ) (Відомості Верховної Ради УРСР, 1981 р., N 20, ст. 290).

2\. Указ Президії Верховної Ради Української РСР від 1 жовтня 1981 року "Про встановлення почесних звань "Заслужений хімік Української РСР" і "Заслужений працівник соціального забезпечення Української РСР" ( 2539-10 ) (Відомості Верховної Ради УРСР, 1981 р., N 41, ст. 674).

3\. Указ Президії Верховної Ради Української РСР від 2 грудня 1981 року "Про встановлення почесного звання "Заслужений працівник фізичної культури Української РСР" ( 2836-10 ) (Відомості Верховної Ради УРСР, 1981 р., N 50, ст. 856).

4\. Указ Президії Верховної Ради Української РСР від 9 лютого 1982 року "Про встановлення почесного звання "Заслужений журналіст Української РСР" ( 3109-10 ) (Відомості Верховної Ради УРСР, 1982 р., N 8, ст. 98).

5\. Постанову Президії Верховної Ради Української РСР від 22 березня 1982 року "Про порядок вручення державних нагород Української РСР" ( 3225-10 ) (Відомості Верховної Ради УРСР, 1982 р., N 14, ст. 181).

6\. Указ Президії Верховної Ради Української РСР від 28 березня 1983 року "Про внесення змін до Положення про державні нагороди Української РСР" ( 4934-10 ) (Відомості Верховної Ради УРСР, 1983 р., N 15, ст. 295).

7\. Постанову Президії Верховної Ради Української РСР від 15 листопада 1988 року "Про вдосконалення порядку нагородження державними нагородами Української РСР" ( 6847-11 ) (Відомості Верховної Ради УРСР, 1988 р., N 48, ст. 1126).

8\. Указ Президії Верховної Ради Української РСР від 15 листопада 1988 року "Про внесення змін у систему почесних звань Української РСР" ( 6848-11 ) (Відомості Верховної Ради УРСР, 1988 р., N 48, ст. 1127).

9\. Указ Президії Верховної Ради Української РСР від 20 квітня 1989 року "Про внесення змін і доповнень до Положення про державні нагороди Української РСР" ( 7389-11 ) (Відомості Верховної Ради УРСР, 1989 р., N 18, ст. 164).

10\. Постанову Президії Верховної Ради Української РСР від 1 серпня 1990 року "Про затвердження форми нагородного листа для представлення до нагородження державними нагородами Української РСР" ( 109-12 ) (Відомості Верховної Ради УРСР, 1990 р., N 33, ст. 489).

11\. Постанову Президії Верховної Ради України від 3 січня 1992 року "Про Комісію Президії Верховної Ради України у питаннях заснування державних нагород України" ( 2029-12 ) (Відомості Верховної Ради України, 1992 р., N 17, ст. 212).

12\. Постанову Президії Верховної Ради України від 2 березня 1992 року "Про громадян України, відзначених державними нагородами СРСР" ( 2159-12 ) (Відомості Верховної Ради України, 1992 р., N 22, ст. 322).

13\. Постанову Президії Верховної Ради України від 15 листопада 1993 року "Про зміни в складі Комісії Президії Верховної Ради України у питаннях заснування державних нагород України" ( 3590-12 ) (Відомості Верховної Ради України, 1993 р., N 46, ст. 432).

III. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 17 травня 2001 року N 2419-III
