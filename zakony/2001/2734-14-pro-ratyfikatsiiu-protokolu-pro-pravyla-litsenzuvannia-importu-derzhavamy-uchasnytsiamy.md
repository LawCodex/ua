# Про ратифікацію Протоколу про правила ліцензування імпорту державами - учасницями Угоди про створення зони вільної торгівлі

ЗАКОН УКРАЇНИ

Про ратифікацію Протоколу про правила ліцензування імпорту державами - учасницями Угоди про створення зони вільної торгівлі

( Відомості Верховної Ради України (ВВР), 2002, N 2, ст.17 )

Верховна Рада України постановляє:

Протокол про правила ліцензування імпорту державами - учасницями Угоди про створення зони вільної торгівлі ( 997\_777 ), підписаний у м. Мінську 30 листопада 2000 року, ратифікувати (додається\*).

Президент України Л.КУЧМА

м. Київ, 20 вересня 2001 року N 2734-III

\_\_\_\_\_\_\_\_\_\_\_\_ \* Додається до оригіналу.
