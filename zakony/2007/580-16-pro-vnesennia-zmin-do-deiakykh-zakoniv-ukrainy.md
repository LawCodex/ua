{ Із змінами, внесеними згідно із Законами N 2269-VIII ( 2269-19 ) від 18.01.2018, ВВР, 2018, N 12, ст.68 N 145-IX ( 145-20 ) від 02.10.2019, ВВР, 2019, N 46, ст.302 }

Закон України "Про особливості приватизації відкритого акціонерного товариства "Укртелеком" ( 1869-14 ) (Відомості Верховної Ради України, 2000 р., N 41, ст. 341; 2003 р., N 37, ст. 300; 2004 р., N 12, ст. 155);
