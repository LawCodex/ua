# Про ратифікацію Конвенції Міжнародної організації праці N 129 1969 року про інспекцію праці в сільському господарстві

ЗАКОН УКРАЇНИ

Про ратифікацію Конвенції Міжнародної організації праці N 129 1969 року про інспекцію праці в сільському господарстві

( Відомості Верховної Ради України (ВВР), 2005, N 1, ст.12 )

Конвенцію Міжнародної організації праці N 129 1969 року про інспекцію праці в сільському господарстві ( 993\_114 ), прийняту 25 червня 1969 року, ратифікувати (додається\*).

Президент України Л.КУЧМА

м. Київ, 8 вересня 2004 року N 1986-IV

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ \* Додається до оригіналу.
