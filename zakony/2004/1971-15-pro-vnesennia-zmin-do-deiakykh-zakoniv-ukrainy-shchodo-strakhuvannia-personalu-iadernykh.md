# Про внесення змін до деяких законів України (щодо страхування персоналу ядерних установок)

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законів України (щодо страхування персоналу ядерних установок)

( Відомості Верховної Ради України (ВВР), 2005, N 1, ст.10 )

{ Із змінами, внесеними згідно із Законом N 1909-IX ( 1909-20 ) від 18.11.2021 }

Верховна Рада України постановляє:

I. Внести до законів України такі зміни:

{ Пункт 1 розділу I втратив чинність на підставі Закону N 1909-IX ( 1909-20 ) від 18.11.2021 }

2\. У статті 15 Закону України "Про використання ядерної енергії та радіаційну безпеку" ( 39/95-ВР ) (Відомості Верховної Ради України, 1995 р., N 12, ст. 81; 1997 р., N 4, ст. 20):

частину першу виключити;

у частині третій слова "обов'язковому і" виключити.

II. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 1 липня 2004 року N 1971-IV
