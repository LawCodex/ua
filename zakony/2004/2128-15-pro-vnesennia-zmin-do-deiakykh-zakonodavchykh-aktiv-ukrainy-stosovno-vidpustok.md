# Про внесення змін до деяких законодавчих актів України стосовно відпусток

ЗАКОН УКРАЇНИ

Про внесення змін до деяких законодавчих актів України стосовно відпусток

( Відомості Верховної Ради України (ВВР), 2005, N 2, ст.36 )

Верховна Рада України постановляє:

I. Внести зміни до таких законодавчих актів України:

1\. Частину першу статті 182-1 Кодексу законів про працю України ( 322-08 ) (Відомості Верховної Ради УРСР, 1971 р., додаток до N 50, ст. 375; Відомості Верховної Ради України, 1998 р., N 43-44, ст. 268; 2003 р., N 15, ст. 110) після слів "усиновила дитину" доповнити словами "одинокій матері".

2\. Частину першу статті 19 Закону України "Про відпустки" ( 504/96-ВР ) (Відомості Верховної Ради України, 1997 р., N 2, ст. 4; 2003 р., N 15, ст. 110) після слів "усиновила дитину" доповнити словами "одинокій матері".

II. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 22 жовтня 2004 року N 2128-IV
