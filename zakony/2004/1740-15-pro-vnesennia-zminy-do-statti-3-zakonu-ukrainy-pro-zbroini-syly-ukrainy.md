# Про внесення зміни до статті 3 Закону України "Про Збройні Сили України"

ЗАКОН УКРАЇНИ

Про внесення зміни до статті 3 Закону України "Про Збройні Сили України"

( Відомості Верховної Ради України (ВВР), 2004, N 33-34, ст. 405 )

Верховна Рада України постановляє:

1\. В абзаці третьому частини другої статті 3 Закону України "Про Збройні Сили України" ( 1934-12 ) (Відомості Верховної Ради України, 2000 р., N 48, ст. 410) слова "Військово-Повітряні Сили, Війська Протиповітряної оборони" замінити словами "Повітряні Сили".

2\. Цей Закон набирає чинності з дня його опублікування.

Президент України Л.КУЧМА

м. Київ, 3 червня 2004 року N 1740-IV
