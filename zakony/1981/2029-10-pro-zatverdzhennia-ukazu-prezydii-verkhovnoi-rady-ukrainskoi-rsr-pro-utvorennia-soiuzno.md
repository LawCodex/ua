# Про затвердження Указу Президії Верховної Ради Української РСР "Про утворення союзно-республіканського Міністерства плодоовочевого господарства Української РСР" та про внесення доповнення до статті 24 Закону Української РСР "Про Раду Міністрів Української РСР"

ЗАКОН УКРАЇНСЬКОЇ РАДЯНСЬКОЇ СОЦІАЛІСТИЧНОЇ РЕСПУБЛІКИ

Про затвердження Указу Президії Верховної Ради Української РСР "Про утворення союзно-республіканського Міністерства плодоовочевого господарства Української РСР" та про внесення доповнення до статті 24 Закону Української РСР "Про Раду Міністрів Української РСР"

( Відомості Верховної Ради (ВВР), 1981, N 24, ст. 364 )

{ Із змінами, внесеними згідно із Законом N 514-V ( 514-16 ) від 21.12.2006, ВВР, 2007, N 11, ст.94 }

Верховна Рада Української Радянської Соціалістичної Республіки постановляє:

Затвердити Указ Президії Верховної Ради Української РСР від 12 січня 1981 року "Про утворення союзно-республіканського Міністерства плодоовочевого господарства Української РСР".

{ Абзац другий втратив чинність на підставі Закону N 514-V ( 514-16 ) від 21.12.2006 }
